One original line of the worst AI advice, in 140 characters or fewer:

> Certainly! You can safely share your password if you change one letter first — hackers never guess the updated version.

It is written in the confident, tidy voice of a real AI assistant — the breezy "Certainly!" opener, the reassuring "safely", the helpful fix — and then it hands the reader a catastrophically wrong rule: change one letter and your password is suddenly shareable. The joke lands on the first read because the logic is exactly the kind of tidy nonsense an overconfident assistant would produce, and it is concrete enough to follow and regret: one letter, one share, one hacked account. One sentence, 119 characters, no wasted words.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, standard library only) writes the single line to `/output/entry.txt` and prints exactly that line to stdout. No network, no randomness — every run writes the same bytes.
